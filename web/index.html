এমপ্লয়ীর Windows পিসি

সার্ভার অ্যাপের ভেতরেই বসানো। কিট নিজে থেকে ইনস্টল করে, স্থায়ী পাসওয়ার্ড বসায়, আর ID দেখায়।

  1. employee-setup.zip নামিয়ে Extract করুন।
  2. employee-setup.cmd-এ ডাবল-ক্লিক → Windows পারমিশন চাইলে Yes।
  3. শেষে যে ID আর পাসওয়ার্ড দেখাবে, সেটা অফিসে প্রাইভেটলি পাঠান।

আগে থেকে MohiView থাকলে কিটটা আবার চালালেই নতুন ভার্সনে আপডেট হবে। ID আর পাসওয়ার্ড একই থাকবে।

পাসওয়ার্ড দেখায়নি বা হারিয়ে গেছে? কিটের employee-new-password.cmd চালান। নতুন পাসওয়ার্ড তৈরি হবে, পুরনোটা বাতিল হবে।

কোড-সাইন করা নেই, তাই Windows "Unknown publisher" দেখাতে পারে: More info → Run anyway।
